# 葉語冒險：倖存者（Leaf Survivors）

俯視角的「倖存者」類網頁遊戲，以手機橫向操作為主。

## 怎麼玩
直接用瀏覽器開啟 `index.html`，不需要安裝或建置。

- 手機：左半邊螢幕是滑動搖桿，可以往八個方向移動；右半邊點一下衝刺，衝刺的瞬間無敵
- 電腦：WASD／方向鍵移動，空白鍵衝刺，P 暫停

## 目前進度：v0.3 職業與轉職
- 4 個職業，各有起始技能、職業特性和不同外觀：
  - 劍士：斬擊，HP 最高、受到傷害 -10%
  - 法師：追蹤魔法彈，HP 最低、技能冷卻 -10%
  - 弓箭手：連射，移速 +10%
  - 盜賊：飛刃，爆擊率 +7%、衝刺冷卻 -40%
- Lv.10 轉職二選一，每條路線有專屬技能和被動，外觀也會改變（披風、頭飾、武器）：
  | 職業 | 路線 A | 路線 B |
  |---|---|---|
  | 劍士 | 劍聖（劍氣） | 鐵壁守護者（聖盾） |
  | 法師 | 元素使（隕石） | 星術師（時空領域） |
  | 弓箭手 | 疾風遊俠（箭雨） | 獸語者（靈狼） |
  | 盜賊 | 分身術士（影分身） | 機關師（地雷） |
- 共用技能：守護劍環、雷霆、烈焰光環、震地擊，加上 6 種被動
- 3 種怪物，每 75 秒有一波怪潮從四面包圍
- 3:00 出現 BOSS，6:00 出現最終 BOSS。BOSS 跳起時落點出現紅圈，落地後的震波要用衝刺穿過
