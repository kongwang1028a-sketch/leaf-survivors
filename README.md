# 葉語冒險：倖存者（Leaf Survivors）

俯視角的「倖存者」類網頁遊戲，以手機橫向操作為主。

## 怎麼玩
直接用瀏覽器開啟 `index.html`，不需要安裝或建置。

- 手機：左半邊螢幕是滑動搖桿，可以往八個方向移動；右半邊點一下衝刺，衝刺的瞬間無敵
- 電腦：WASD／方向鍵移動，空白鍵衝刺，P 暫停

## 目前進度：俯視版原型 v0.2
- 1 個職業（劍士），6 種攻擊技能和 6 種被動能力，升級時三選一
- 3 種怪物，每 75 秒有一波怪潮從四面包圍
- 3:00 出現 BOSS，6:00 出現最終 BOSS。BOSS 會跳向玩家，跳起時落點出現紅圈，落地後的震波要用衝刺穿過
- 經驗、金幣、寶箱、最佳紀錄（存在瀏覽器的 localStorage）

## 開發路線
1. 原型：確認手感 ✅
2. 4 個職業加轉職分支
3. 局外養成：金幣、裝備、強化、存檔
4. 打磨：音效、特效、數值平衡

橫向卷軸版保留在 tag `v0.1-side`。

所有角色、怪物與美術都是原創，以 Canvas 程式繪製。
